## How it works

Run `python3 main.py`. It writes one confession line (124 characters, a single line, no trailing newline) to `/output/entry.txt`, falling back to `./output/entry.txt` when `/output` is not writable. The line is validated first: non-empty, single line, at most 200 characters.
